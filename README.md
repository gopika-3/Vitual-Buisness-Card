# Virtual Business Card

A modern and interactive virtual business card built using HTML, CSS, and JavaScript. The project presents personal and professional information in a clean, responsive digital format.

## Features

- Interactive profile photo
- Professional name, role, and tagline
- Clickable email and phone contact information
- LinkedIn, GitHub, and Instagram links
- QR code linking to LinkedIn
- Resume access button
- Portfolio button
- Smooth entrance animations
- Interactive hover effects
- Responsive design
- Modern navy, cream, and gold color scheme
- Reduced-motion support for accessibility

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
